# The RT64 shaders the web page builds: one shader description a line, other mode L and H, color combiner L and H,
# flags, in hex. RT64 specializes each one's WGSL when the page is built and builds them with the game waiting: those
# above the first "section" line before the game starts, and a section when a frame first wants 4 of its shaders,
# so that nothing draws with the ubershader, which integrated graphics can't afford (N64Recomp-browser's README,
# "Give RT64 a list of the game's shaders").
#
# Recorded by playing, a page load a section: N64Recomp-browser's tools/record_shaders.mjs with tools/shader_plan.json,
# which drives the menus with the default keys and knows where the game is by its loaded modules
# (tools/game_state.js) and the console line the game prints as it loads a course. Section 0 is the launcher, the
# intro, the title and its demo on Crystal Lake, and the menus: Match Race's level select, Time Attack's rider, board
# and course select. Then the three courses a new save has, a Match Race on Crystal Lake, 100 s of it, and Time Attack
# on Crystal Peak and on Golden Forest, 90 s each, and Training's course, 60 s. Not recorded: the courses a save opens
# later (Mountain Village, Dragon Cave, Deadly Fall, the Half Pipe and Air Make), Trick Attack, Contest and 2P VS,
# and a race's end past the time ridden. Flags follow settings (filtering, HDR, upscaling), so a change to one of
# those defaults means recording again.
